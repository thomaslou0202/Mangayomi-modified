# Mangayomi 0.9.95+146

- 修正書庫篩選、排序與顯示方式偶爾被重設：同步時改為保留本機的書庫篩選與每部作品的章節排序／篩選，不再被其他裝置的設定蓋掉。
- 小說連續閱讀與漫畫更早開始預載下一章，接續閱讀時較少看到載入中。
- 閱讀進度、標記已讀與閱讀紀錄改在背景寫入，背景同步進行中翻頁也不會卡住。
- 同步進度條在有刪除紀錄時也能跑到 100%。
- 書庫「繼續閱讀」列、全域搜尋與批次下載不再拖慢操作；封面載入失敗不再記成錯誤報告。
- 包含 +143 的開書、讀正文與瀏覽來源不再沒有回應的修正。

手機可直接安裝新版覆蓋更新，不需清除書庫。建議同時更新擴充套件：嗶哩輕小說 0.1.7（修正插圖章節）、KadoKado 角角者 0.1.1（新來源，正文需在內建網頁登入）。
Windows 更新前請先關閉 Mangayomi。
