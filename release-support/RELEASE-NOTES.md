# Mangayomi 0.9.95+149

- 修正同步後檢查點可能退回舊值、造成重複同步。
- 下載與備份路徑、各作品的頁碼與閱讀模式等本機設定不再被其他裝置同步覆蓋，Windows 的路徑不會寫進手機。
- 修正「將下方標記為已讀」在選到最後一話時當機，或從第一話開始全部標成已讀。
- 書庫「已開始」篩選改為至少讀過一章，不再和「未讀」相同。
- 同步過來的更新紀錄會出現在更新頁。
- Cookie 不再送給名稱相近的其他網站。
- 修正擴充套件與網路連線長時間使用後記憶體越佔越多；開啟 DoH 或自訂 DNS 時，連線逾時等設定恢復正常。
- 下載進度更新時書庫不再整個重算，小說下載每章少等 1 秒，點選來源更快。
- 小說正文中的 <技能> 這類文字不再消失；連續閱讀時朗讀會唸目前這一章。
- App 內更新改為邊下載邊寫入並驗證檔案完整性，下載時不再佔用大量記憶體。

手機可直接安裝新版覆蓋更新，不需清除書庫。
Windows 更新前請先關閉 Mangayomi。
